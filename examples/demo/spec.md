# SPEC demo: saludo del repositorio

## Objetivo
Dejar constancia de que Batuta recorre el flujo completo: dos archivos nuevos
con un saludo, verificados con gates triviales.

## Requisitos
- R-1: crear `saludo.txt` con una línea de saludo.
- R-2: crear `despedida.txt` con una línea de despedida.

## Archivos permitidos
- `saludo.txt`
- `despedida.txt`

## Criterios de aceptación
- CA-1: existen los dos archivos | verificación: gate `ok`
